HGTV 手机端 0.1.8

## 本次更新

- **修复 0.1.7 的「进片空响应、无法播放」**。服务端从 11-17 起要求 Android v5 播放签名，
  上一版「本机 Argus/Ladon、不带 medusa」被拒绝，一律返回 200 + 空包。
- **播放签名升级为 v5**（`v04.10.03`），与电视端、Windows 端共用同一套 core 实现：
  gzip 请求体、移动版 profile、请求只带 `x-khronos` / `x-helios` / `x-medusa` 三个头，
  精确绑定最终 query 与 body。签名常量与算法有单测逐字节对齐。
- 播放身份改用匿名注册，与搜索/目录签名（仍走 v3）隔离；旧路径保留作降级。
- **安装包没有变大**。播放链路纯 Kotlin，没有内置任何第三方签名库。

真网络验证（同一集）：v5 返回 5 档可解码 HEVC（360P ~ 1080P），旧路径复现空响应。

其余功能与 0.1.7 一致：并发弹幕与 ×N 合并、官方 53 个表情、跨季连播、整季单播放列表换集、
长按 2 倍速、选集缩窗。

## 下载

`hgtv-phone-0.1.8.apk`，同目录下有 `sha256sum.txt`。安装包与电视端同一套签名证书，
可以直接覆盖安装 0.1.1 ~ 0.1.7，本地收藏、观看记录与登录态都不会丢。

v5 播放走匿名注册，不再依赖 `device-identity.txt`；该文件仅作旧路径降级使用，放不放都能播。
