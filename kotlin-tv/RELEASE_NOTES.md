HGTV 0.1.23 更新说明

这一版只加一件事：进应用就能接着上次看。

首页
- 首页顶部新增「继续观看」，显示本机最近一条观看记录：剧名、第几集、看到哪。
- 按一次确定直接续播那一集，不用先进详情页再点播放。
- 整集已看完时改为「接着看下一集」，从下一集开头开始。
- 入口只读本机记录，首页推荐还在加载或加载失败时也照样能用。
- 本机没有观看记录时不占位，首页布局与原来一致。

Windows 端
- 首页同样新增「继续观看」，在标题行下方：封面、剧名、进度与一个续播按钮。
- 本机页标签顺序调整为「观看记录」在前、「本机收藏」在后。

说明
- 不改变安装标识与签名，可直接覆盖安装 0.1.22。支持 Android 6.0 及以上。
- Windows 客户端仍随 Release 附带的压缩包分发，版本号未单列。
