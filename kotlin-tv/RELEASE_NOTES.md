HGTV 0.1.33 更新说明（TV + Windows）

这一版修复 0.1.32 发版后出现的「进片空响应、无法播放」问题。播放签名改用已验证可用的 Android v5 方案。

两端共同
- **播放签名升级为 v5**（`v04.10.03`）。0.1.32 的「本机 Argus/Ladon、不带 medusa」方案在 11-17 起被服务端拒绝，一律返回 200 + 空包。这一版改用 v5 medusa / helios / khronos：请求体 gzip、移动版 profile、精确绑定最终 query 与 body，请求只带这三个签名头。
- 签名常量与算法移植自另一套已验证可播放的实现，含 32 个独立摘要向量 + 4 种载体变体的单测，逐字节对齐。
- 播放身份改用匿名注册，与本机搜索/目录签名（仍走 v3）完全隔离，互不干扰。
- 保留 0.1.32 的旧路径作降级：新签名任何环节失败会自动回退，不会比上一版更差。

修复验证
- 真网络对拍（同一集）：v5 路径返回 5 档可解码 HEVC（360P/480P/540P/720P/1080P）；关掉 v5 的旧路径复现空响应。
- core 全量单测、TV 编译与 lint 全部通过。

TV 端 / Windows 端
- 无需改任何设置。设置页「签名服务（兜底）」留空即可，播放不依赖外部签名服务。
- 版本号与 TV 对齐为 0.1.33，便携包文件名带版本号。

使用前提
- 不需要签名手机、不需要 adb、不需要 root。装好直接播放。
- `device-identity.txt` 仍可选：v5 播放走匿名注册，不再依赖它；本地身份仅作旧路径降级使用。

说明
- 不改变安装标识与签名，可直接覆盖安装 0.1.32。支持 Android 6.0 及以上。
- Windows 便携包解压即用，无需额外运行时；BVC2 软解仍需自备 FFmpeg。
- 建议重点验证：进片出画、连续换集、切换清晰度是否正常。
