HGTV 0.1.20 更新说明

这一版让「设备身份配置」不再静默：读到配置、以及配置在播放中失效，两端都会明确提示一次。

新增
- 电视端与 Windows 端在读取到 device-identity.txt 后给出提示，说明已生效、播放将跳过设备注册。
- 配置在播放中被服务端判为失效时给出提示，说明已自动改为注册设备，播放不受影响。
- 提示每个进程只出现一次：同一份配置不重复提示，换文件或换值才会再次提示；没有配置时不提示，因为自动注册是正常路径。

Windows 端
- 底部状态栏常驻显示设备身份配置状态，运行中新增、删除或修改配置文件会在几秒内反映出来。
- 配置状态发生变化时弹出一条提示，其余时间保持安静。

其他
- 附带设备身份读取工具的源码（tools/device-identity-reader），可在有 root 的手机上读取官方客户端的设备信息。

说明
- 不改变安装标识与签名，可直接覆盖安装 0.1.19。支持 Android 6.0 及以上。
