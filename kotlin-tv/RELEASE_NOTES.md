HGTV 0.1.21 更新说明

这一版解决「配置放好了却完全没反应」的两类静默失败：电视端缺存储权限、Windows 端放错目录。

电视端
- 首次启动若缺少读取 /sdcard/ 的权限，弹一次说明并给出直达系统开关的入口，不再默默读不到。
- 设置页新增「设备身份配置」一行，可随时看到「已读取（尾号 xxxx）／需授权／未放置」，点进去分别查看读取路径、开启权限或说明怎么放置。
- 从系统设置开完权限返回即刻生效，不必重启 App。
- 顺带修好 Android 6 至 10：这类设备以前从未在运行时申请过存储权限，同样读不到配置。

Windows 端
- 配置可以放在 hgtv_windows.exe 同级的程序目录，与文档和直觉一致；仍兼容 bridge 子目录与用户目录下的 .hgtv。
- 设置页新增「设备身份」区块，显示当前是否读到、读到的是哪个文件；没配置时直接给出该放到哪里。
- 附带电视模拟器启动脚本（scripts/start-tv-emulator.sh），方便自行验证界面改动。

说明
- 不改变安装标识与签名，可直接覆盖安装 0.1.20。支持 Android 6.0 及以上。
- Windows 客户端仍随 Release 附带的压缩包分发，版本号未单列。
