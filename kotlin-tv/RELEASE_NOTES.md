HGTV 0.1.34 更新说明（TV + Windows）

本次为设置项清理版，移除已失效的播放配置项，播放链路与 0.1.33 一致，无需任何手动配置。

两端共同
- **移除「设备身份配置」**：v5 播放走匿名注册、不读取 `device-identity.txt`，设置页里这项配置与相关提示已全部删除；电视和 Windows 不再申请「所有文件访问 / 读取存储」权限。
- **移除「签名服务（兜底）」**：播放签名为纯本机 v5 实现，不依赖外部签名服务，设置页入口与诊断里的签名服务状态一并删除。
- 设置页更简洁，只保留真正会改变行为的选项（清晰度、倍速、弹幕、自动连播、主题、账号、更新等）。

修复验证
- 三端 Kotlin 编译、core 与 TV 全量单测、Windows Flutter 静态分析（flutter analyze）全部通过。

TV 端 / Windows 端
- 无需改任何设置，装好直接播放。
- 版本号与 TV 对齐为 0.1.34，便携包文件名带版本号。

使用前提
- 不需要签名手机、不需要 adb、不需要 root，也不需要放置任何设备身份文件。装好直接播放。

说明
- 不改变安装标识与签名，可直接覆盖安装 0.1.33。支持 Android 6.0 及以上。
- Windows 便携包解压即用，无需额外运行时；BVC2 软解仍需自备 FFmpeg。
- 建议重点验证：进片出画、连续换集、切换清晰度是否正常。
