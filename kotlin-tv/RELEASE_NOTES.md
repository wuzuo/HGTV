HGTV 0.1.26 更新说明

这一版修的是「检查更新失败」，顺带把上一版的两件事一起发出。

更新检查
- 上一版发布后，手机端首发占用了仓库的「最新发行版」位置，TV 端读到的就成了
  那个没有更新清单的发行版，检查更新直接报格式错误。
- 现在优先读「最新发行版」，它被别的产品线顶掉时退回到发行版列表里，
  只认带 `kotlin-v*` 标签且带更新清单的那一条。两条路都失败才报错，
  并且会把真实原因（例如确实还没有可更新的版本）如实显示出来。
- 手机端以后的发版也不再抢占这个位置，两条产品线的发版互不影响。

修复
- 有些剧集会固定在某几集播放失败，重试、换清晰度都不行，换别的集又正常。
- 原因是自动学习解码能力的逻辑记错了账：设备在内存回收时偶发崩溃被当成了
  「这个编码 + 这个分辨率解不了」，于是这一档被永久停用。
- 现在只把真正的解码失败算作能力不足，崩溃中断不再写入学习记录；同时加了自愈：
  某个尺寸被判死而后备档位全空时，会用实测能力再试一轮，成功了就撤销误判。
- 诊断页会列出具体的学习记录条目，方便核对是哪一档被记错。

手机端（首次发布，独立安装包）
- 与 TV 端共用协议层与播放层，界面为触摸屏重写，竖屏操作。
- 首页瀑布流、搜索、详情、收藏与观看记录、续播、登录、设置都已具备。
- 播放页支持拖动调进度、左右半屏调亮度与音量、双击快退快进、弹幕、
  清晰度与倍速切换、选集、评论、后台播放与画中画。
- 包名不同（io.github.wuzuo.hgtv.phone），可与 TV 端装在同一台设备上互不影响。

说明
- 不改变安装标识与签名，可直接覆盖安装 0.1.24 / 0.1.25。支持 Android 6.0 及以上。
- 建议重点验证之前固定失败的那几集，以及连续快进、连续切集的操作。
- 手机端安装包见手机端的 Release（标签 phone-v 开头）。
- Windows 客户端仍随 Release 附带的压缩包分发，版本号未单列。
