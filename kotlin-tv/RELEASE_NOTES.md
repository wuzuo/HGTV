HGTV 0.1.35 更新说明（TV + Windows）

本次为播放修复版，恢复被服务端空响应打断的播放链路，三端共用 core 已同步更新，无需任何手动配置。

修复内容
- **修复播放空响应**：此前部分剧集在 v5 播放请求后走降级链路拿不到数据，返回空响应导致无法播放。现已按已验证可用的实现修正：降级用的 `video_tab/multi_video_model` 请求改用 v5 签名（空 body 参与签名、按 GET 发出并移除 body 相关请求头），空响应问题已修复。
- 真机网络验证：集号 `7696131808160648216` 可正常返回 `1080p bytevc1`（1080×1920），与参考实现结果一致。

两端共同
- 播放签名为纯本机 v5 实现，不依赖外部签名服务，也不需要设备身份文件。
- 设置页保持简洁，只保留真正会改变行为的选项（清晰度、倍速、弹幕、自动连播、主题、账号、更新等）。

修复验证
- 三端 Kotlin 编译、core 与 TV 全量单测（含签名 oracle 对拍）、真网络出片探针全部通过。

TV 端 / Windows 端
- 无需改任何设置，装好直接播放。版本号与 TV 对齐为 0.1.35，便携包文件名带版本号。
- Windows 便携包内的 bridge 从共享 core 重新构建，播放链路与 TV 一致。

使用前提
- 不需要签名手机、不需要 adb、不需要 root，也不需要放置任何设备身份文件。装好直接播放。

说明
- 不改变安装标识与签名，可直接覆盖安装 0.1.34。支持 Android 6.0 及以上。
- Windows 便携包解压即用，无需额外运行时；BVC2 软解仍需自备 FFmpeg。
- 建议重点验证：进片出画、连续换集、切换清晰度是否正常。
