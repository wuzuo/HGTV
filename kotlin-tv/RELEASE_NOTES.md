HGTV 0.1.31 更新说明（TV + Windows）

这一版让电视和 Windows 都能把播放签名交给「手机上的独立签名服务」，解决播放接口返回空包、进片不出画面的问题。签名机装在手机上，打开红果就在局域网监听 18089，不用 adb、不用 root、也不用电脑常驻。

两端共同
- 播放接口的 X-Medusa 等签名头改由真机计算；服务会顺带把 device_id / iid / install_id 对齐到签名手机的当前身份，网络请求仍由本机发出。
- 没配服务或连不上时自动回退本机签名，行为与旧版一致，不会卡住播放。
- 修复播放接口显式带 Accept-Encoding: gzip 时未解压、被误判成「非 JSON」的问题。

TV 端
- 「设置 → 签名服务」可直接填写或清除地址；「播放诊断」显示签名成功/失败次数与上次错误，不用 adb 改配置。
- 放开局域网 HTTP 明文限制，任意内网 IP 的签名服务都能连；也支持编译时用 HGTV_SIGNING_SERVICE 注入默认地址。

Windows 端
- 「设置 → 签名服务」新增地址输入与开关，写入 settings.json，启动时自动带上；运行中修改会立即下发给本机服务，不必重启客户端。
- 版本号与 TV 对齐为 0.1.31，便携包文件名带版本号。

使用前提
- 签名机 APK 不在本次 Release 附件里，需单独装到一台安卓手机；手机与电视/电脑在同一局域网，红果保持后台运行，手机重启后打开一次即可。
- 手机 IP 变化后，在两端设置页改地址（建议给手机固定 IP）。

说明
- 不改变安装标识与签名，可直接覆盖安装 0.1.30。支持 Android 6.0 及以上。
- Windows 便携包解压即用，无需额外运行时；FFmpeg 需自备。
- 建议重点验证：开启签名服务后进片能否出画面，以及关掉服务后是否只回退本机签名、不影响首页浏览。
