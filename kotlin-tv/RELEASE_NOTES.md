HGTV 0.1.36 更新说明（TV + Windows）

本次为播放修复版：服务端变更导致 0.1.35 再次出现空响应，已按已验证可用的新协议修复，三端共用 core 同步更新，无需任何手动配置。

修复内容
- **修复播放空响应**：服务端现要求 currentApp 协议（7.4.5.32 / preload 端点）与完整 v5 设备信封。此前 0.1.35 的精简签名被服务端拒绝返回空包；现已补齐 medusa 设备信封全部字段、修正 wire field21，并将播放请求切到新协议（失败时仍保留 GET video_tab 与备用 host 降级）。
- 真机网络验证：集号 `7696131808160648216` 返回 5 档 bytevc1（360p / 480p / 540p / 720p / 1080p，最高 1080×1920），与参考实现结果一致。

两端共同
- 播放签名为纯本机 v5 实现，不依赖外部签名服务，也不需要设备身份文件。
- 设置页保持简洁，只保留真正会改变行为的选项（清晰度、倍速、弹幕、自动连播、主题、账号、更新等）。

修复验证
- 三端 Kotlin 编译、core 与 TV 全量单测（含签名 wire-contract 对拍）、Windows Flutter 静态分析、bridge 编译，全部通过。
- 真网络出片探针通过。

TV 端 / Windows 端
- 无需改任何设置，装好直接播放。版本号与 TV 对齐为 0.1.36，便携包文件名带版本号。
- Windows 便携包内的 bridge 从共享 core 重新构建，播放链路与 TV 一致。

使用前提
- 不需要签名手机、不需要 adb、不需要 root，也不需要放置任何设备身份文件。装好直接播放。

说明
- 不改变安装标识与签名，可直接覆盖安装 0.1.35。支持 Android 6.0 及以上。
- Windows 便携包解压即用，无需额外运行时；BVC2 软解仍需自备 FFmpeg。
- 建议重点验证：进片出画、连续换集、切换清晰度是否正常。
