HGTV 0.1.12 更新说明

首个以「HGTV」名义正式发布的版本，应用名称、图标与安装标识一并更新。

新增
- 弹幕：可选「只显一行 / 上方显示 / 全屏显示 / 隐藏」，速度、字号、透明度均可调；重复弹幕会合并为一条并显示 ×N，表情标签直接渲染成图片。
- 应用内更新改为从 GitHub Releases 检查新版本，下载后按 SHA-256 校验，通过后再交给系统覆盖安装。

修复
- 部分影片播放接口返回空结果的问题（改为注册并共享匿名播放设备）。

其他
- Windows 客户端同步支持弹幕与新的更新源，安装包作为附件一并发布在本 Release。

注意：安装标识已从 com.hgtv.tv 改为 io.github.wuzuo.hgtv，旧版无法覆盖升级，本版需单独安装，本机数据与登录状态不会继承；同时发布签名已更新，此后各版本均沿用新签名。支持 Android 6.0 及以上。
