HGTV 0.1.29 更新说明

这一版把「整集只有 BVC2 编码」的兜底做到底：上一版靠换设备身份让服务端回 HEVC，
服务端不给的时候仍然播不了；现在 Windows 端可以自己软解。

Windows 端
- 遇到整集只有 BVC2（H.266）的剧集，改用本机 FFmpeg 解码后重新编码成本机 HLS 播放，
  不再提示「换一集」。
- 第一次播放会先下载并解密该集资源，再转出首段才能起播，通常要等十几秒到半分钟，
  期间窗口会停在上一个画面，属正常现象；之后的拖动会从最近的转码点续上。
- 需要本机有 FFmpeg：在 PATH 里能找到即可，也可以用环境变量 HGTV_FFMPEG 指定路径。
  找不到时会明确提示，不再是模糊的播放失败。
- 只在真的播不了时才走这条路；正常剧集和能自动降级到 HEVC 的剧集不受影响，
  不会有额外等待，也不会占用 CPU 转码。

TV 端
- 播放逻辑与 0.1.28 相同，本版没有行为变化，只为与桌面端保持同一版本号一起发布。

说明
- 不改变安装标识与签名，可直接覆盖安装 0.1.28。支持 Android 6.0 及以上。
- 便携包解压即用，无需额外安装运行时；FFmpeg 需自备。
- 建议重点验证之前固定失败的那一集在 Windows 端的起播，以及转码期间的暂停、
  拖动与切集。
