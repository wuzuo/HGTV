HGTV 0.1.30 更新说明

这一版把弹幕的加载与表情统一到三个端：进片不用再一页页串行等弹幕，表情也换成官方那套。

弹幕（TV / 手机 / Windows 三端）
- 弹幕窗口改成并发拉取：先单独取第一个窗口拿到服务端给的时间步长，其余窗口同时请求，
  谁先到就先上屏。进片不必等整集预取完，拖动进度条也不会重复请求已经取过的段。
- 服务端按 30 秒切窗的规则不变；个别窗口失败时只从缺口重取，已经到手的弹幕不会丢。
- 弹幕与评论里的表情换成官方 53 个图，三个端共用同一份资源，标签和图片不会再对不上。

TV 端
- 本季最后一集播完后自动接下一季第 1 集，「下一集」按钮同样支持；剧名、分集与弹幕跟着重载。
- 播放接口拿不到可用模型时，错误信息会写明是空 body、非 JSON 还是业务码，排查更明确。

Windows 端
- 弹幕改为一次并发取完整集，去掉分页游标与本地合并逻辑；上一版的 BVC2 软解兜底不变。

说明
- 不改变安装标识与签名，可直接覆盖安装 0.1.29。支持 Android 6.0 及以上。
- 便携包解压即用，无需额外安装运行时；FFmpeg 需自备。
- 建议重点验证进片第一屏弹幕出现的时机，以及拖动、换集、跨季接续时弹幕是否跟着刷新。
