HGTV 0.1.27 更新说明

这一版修的是「某些剧集点开就报 Source error」。

播放失败
- 有些剧集固定某一集播不了，重试、换清晰度都没用，同剧其他集正常。
- 原因是播放请求把设备报成了高档机（device_level=3），服务端据此给这些集只下发
  BVC2（H.266）编码。这个编码没有公开的系统解码器，整集被判成「没有可播放的清晰度」。
- 现在按设备的实际解码能力上报（device_level=1），同一集改为下发 HEVC，分辨率不变。
  实测同一集从全档 bytevc2 变成全档 bytevc1，TV 端与 Windows 端播放正常。

提示文案
- 「没有电视可播放的清晰度」这类提示按原因分开了：真的只有 BVC2 时会明确说
  「这一集只有 BVC2（H.266）编码，当前设备没有对应解码器，请换一集」，不再建议
  「稍后再试」让人反复重试。
- 编码不支持属于确定性错误，手机端也不再自动重试三次。

说明
- 不改变安装标识与签名，可直接覆盖安装 0.1.26。支持 Android 6.0 及以上。
- Windows 端与 TV 端共用协议层，同一版便携包一起发出，症状同步修复。
- 建议重点验证之前固定失败的那一集，以及连续切集、快进后退。
