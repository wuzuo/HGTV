HGTV 0.1.24 更新说明

这一版修的是「播着播着应用直接消失」。这次抓到了根因。

修复
- 某些剧集的某几集，播到一半或连续切集时进程会突然退出，没有任何提示。
- 抓到三次系统崩溃记录，崩的地方都在 Android 运行时自己的内存回收里，
  不是解码器，也不是画面渲染。
- 根因是播放在读取视频数据时产生的临时对象太多：每读 32KB 就要造出约 430KB 垃圾，
  播放时每秒触发一到两次内存回收，单次停顿 126 到 380 毫秒，三成以上的 CPU
  时间花在回收上。设备内存本来就紧张，回收跑得这么密，就容易撞上运行时自身的缺陷。
- 现在解密结果直接写进播放器的读取缓冲区，不再为每段数据反复复制、不再为对齐
  额外拼接。同样一次 32KB 读取的临时对象从 439KB 降到 5.9KB，约减少到原来的 1/75。
- 顺带修掉连续快进后偶发的「播放出错、只能手动重试」：这类错误码现在会自动退避重试。

诊断
- 每集第一次播放失败会记一条诊断，包含集数、清晰度、编码、分辨率与画面输出方式。
- 播放记录补充可用内存、低内存标记、堆大小与开机时长，用于区分「原生崩溃」与
  「被系统回收」。

说明
- 不改变安装标识与签名，可直接覆盖安装 0.1.23。支持 Android 6.0 及以上。
- 建议重点验证之前会退出的那几集，以及连续快进、连续切集的操作。
- Windows 客户端仍随 Release 附带的压缩包分发，版本号未单列。
