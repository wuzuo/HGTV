HGTV 0.1.32 更新说明（TV + Windows）

这一版把播放签名搬回本机：不再需要手机签名服务、不需要电脑常驻，装好就能直接出片。

两端共同
- **播放签名在本机完成**。`x-argus` / `x-ladon` 按官方算法重写（Simon 64/128 加密 + 551 包装 + AES-CBC、34 轮 ARX），单测与已知正确输出逐字节对齐；播放请求不再附带 `x-medusa` / `x-helios`。
- 之前进片不出画面、接口只回 200 空包的根因就在这里：播放网关只硬校验 `x-argus` / `x-ladon`，而本机算出的 `x-medusa` 结构与真机不一致，**带上它反而被静默拒绝**，去掉就正常出片。
- 「签名服务」降级为兜底：只有本机签名抛异常时才交给外部服务（手机独立签名版 / unidbg 容器）。设置页说明与默认文案已同步，留空即可。

TV 端
- 设置项由「签名服务 · 未启用」改为「签名服务（兜底） · 未启用」，对话框明确写出「留空就行」，不再暗示不配就播不了。
- 「播放诊断」仍能看到身份来源与签名失败次数，排查时不用连电脑。

Windows 端
- 设置页「签名服务」区块改为「签名服务（兜底）」，说明改为「可选，一般不用填」。
- 关闭远程签名时的提示改为「已关闭，播放只用本机签名」。
- 版本号与 TV 对齐为 0.1.32，便携包文件名带版本号。

使用前提
- 不需要再准备签名手机、不需要 adb、也不需要 root。装好直接播放。
- 可选：把自己设备上官方客户端的播放身份放进 `device-identity.txt`，可以完全免掉每集一次的设备注册（TV：`/sdcard/hgtv/device-identity.txt`；Windows：`hgtv_windows.exe` 同级目录或 `%USERPROFILE%\.hgtv\`）。不放也能播，只是每播一集多注册一次设备。

说明
- 不改变安装标识与签名，可直接覆盖安装 0.1.31。支持 Android 6.0 及以上。
- Windows 便携包解压即用，无需额外运行时；BVC2 软解仍需自备 FFmpeg。
- 建议重点验证：没有配置任何签名服务时进片能否出画，以及连续换集是否稳定。
