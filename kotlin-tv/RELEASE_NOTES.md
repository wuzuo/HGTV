HGTV 0.1.16 更新说明

本次修掉一个很烦人的播放故障：偶发「播放信息接口返回空响应」，只能关掉应用重开才能继续看。电视端和 Windows 客户端是同一套播放内核，两端一起修好了。

修复
- 播放时提示「播放信息接口返回空响应」，重试和等待都没用，必须退出应用再打开才恢复。原因是平台的内容接口按「设备号 + 安装号」这对匿名身份放行，而客户端整个进程只注册一次、一直复用同一对身份；一旦服务端把这对身份判成过期或限流，之后每次请求都只回一个空响应，客户端再怎么退避重试也是白等。现在检测到空响应（或设备未被放行）时，会自动换一对新的设备身份重新注册并重试一次，不用再关应用。
- 换过身份的那次重试只保留两次读取预算：如果换完身份依然拿不到数据，会立刻报错让你重试，不会把人拦在加载动画里等四五秒。
- 其他接口（搜索、榜单、详情等）的重试次数完全不变，行为与 0.1.15 一致。

说明
- Windows 客户端可直接替换 0.1.15 的文件夹，配置文件与观看记录保留。
- 本次不改变安装标识与签名，可直接覆盖安装 0.1.15。支持 Android 6.0 及以上。
