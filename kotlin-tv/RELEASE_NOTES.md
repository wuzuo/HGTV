HGTV 0.1.22 更新说明

这一版修播放兼容与首页体验：部分 1080P 花屏闪退、个别剧集根本打不开，以及首页总是刷到同一批。

电视端播放
- 部分设备（如 Rokid Station 这类 Amlogic 芯片）播放 1080P 会花屏并直接闪退。新增「画面输出」兼容档（TextureView），设置页与播放内「播放设置」都能切换。
- 播放中异常中断后，下次启动会自动切到兼容档并提示，随时可以改回。
- 设置页新增「播放诊断」，记录异常中断与崩溃信息，可查看、复制。
- 整集只有 bytevc2 编码的剧集会提示「没有电视可播放的清晰度」而完全打不开，现在会先换一次兼容供给再播；仍有可用清晰度的剧集不受影响。

首页
- 冷启动接着上次看，不再每次开机都从同一批开始。
- 换一批不再大段重复上一批，已展示过的作品会跳过。
- 登录后首页报错空转（110）已修；请求失败时自动换备用线路重试，不必等下次刷新。

账号
- 手机号从未在官方 App 侧建立过资料时，提示改为「请先用官方红果 App 登录一次（或改用扫码）」，不再让人反复重试登录。

Windows 端
- 推荐与播放兼容同步生效；首页进度会保存，重开客户端接着上次继续。

说明
- 不改变安装标识与签名，可直接覆盖安装 0.1.21。支持 Android 6.0 及以上。
- Windows 客户端仍随 Release 附带的压缩包分发，版本号未单列。
